# 中国天气图合规边界

更新日期：2026-07-27

## 已确定

- 中国主页地图服务选用国家地理信息公共服务平台（天地图）。
- 开发预览已使用用户从天地图下载的 `中国_省.geojson` 绘制国界、省界和境界线；文件采用 EPSG:4490，共 42 个要素，SHA-256 为 `3af8294f9ad61cc2bf84c1bb7e4bbf86a6336c68d754b699a0e6ddc33ef81486`。
- 接口使用 `vec_w` 矢量底图、`cva_w` 注记和 `ibo_w` 全球境界，目标内容包括国界、省界、省会以上城市、主要河流和湖泊。
- 底层在线地图服务标示审图号 `GS（2024）0568号`，页面必须同时保留来源名称和该号码。
- 服务令牌只从 `TIANDITU_TOKEN` 读取，生产令牌应限制到 `meteostation.top` 等实际使用域名且不得提交仓库。

## 必须区分的两个号码

1. **底图服务来源审图号**：说明所调用的天地图在线地图服务。
2. **本站专题地图审图号**：说明在底图上叠加气象场、探空站、气旋和高低压中心后的最终成图。

前者不能替代后者。项目当前只记录了底图服务来源审图号，本站专题地图仍处于 `pending`，因此 `publication_allowed=false`。

## 当前保护措施

- 正式产品目录不接受未完成合规检查的成图。
- 边界开发预览写入独立的 `data/previews/`，图内固定显示 `OFFICIAL BOUNDARY PREVIEW` 和 `NOT FOR PUBLICATION`。
- 页面来源栏只显示地图来源和适用的服务审图号；令牌及本站专题图送审状态不混入该来源文案。
- 不使用仓库旧代码中的第三方自绘边界作为正式中国国界。
- 没有 `TIANDITU_TOKEN` 时仍可使用已登记的本地天地图省界文件，但不静默回退到第三方边界。

## 正式发布前检查

- 配置域名受限天地图令牌并验证 `vec_w`/`cva_w`。
- 核对国界、省界、重要岛屿和注记完整性，不遮盖、裁切或错误表达。
- 固定最终图幅、投影、裁切范围、图例、站点与气象叠加样式。
- 按实际互联网公开发布用途提交气象专题地图审核。
- 将取得的本站专题地图审图号写入配置和页面，再开启正式产品发布。

政策与服务入口应以自然资源主管部门和天地图官网的最新要求为准。
