## 当前可用

- `/`：开发预览主页。
- `/observations`：气象站过去 24h / 历史日期静态实况查询。
- `/api/v1/observations/plot?station=58362&mode=past24h`：即时生成静态 PNG。
- `/api/v1/observations/plot?station=58362&mode=history&date=YYYY-MM-DD`：即时生成历史日期 PNG。
- `/api/v1/observations/realtime/58367`：q-weather 实时状态。
- `/api/v1/health`：服务健康检查。
- `/api/v1/status`：模块与数据源规划状态。
- `/api/v1/soundings/{station_id}?date=YYYY-MM-DD&cycle=00`：Wyoming 探空廓线。
- `/api/v1/soundings/{station_id}/raw?date=YYYY-MM-DD&cycle=00`：归档源 CSV。
- `/api/v1/soundings/{station_id}/correct?date=YYYY-MM-DD&cycle=00`：非破坏性地面订正与诊断重算。
- `/api/v1/collector/status`：后台采集器最近运行状态。
- `/api/v1/weather-maps/config`：天气图层、分析方法与底图状态。
- `/api/v1/weather-maps/products?date=YYYY-MM-DD&cycle=00&layer=500`：已保存天气图目录。
- `/api/v1/weather-maps/jobs?date=YYYY-MM-DD&cycle=00`：天气图任务及输入阻塞状态。
- `/api/v1/weather-maps/previews?date=YYYY-MM-DD&cycle=00&layer=500`：带本地天地图省界的天气场开发预览目录。
- `/api/v1/weather-maps/sounding-stations?date=YYYY-MM-DD&cycle=00`：88 个 Wyoming 中国探空站的本地归档更新状态。
- `/forecast`：IFS/AIFS三天单点预报图。
- `/sounding-forecast`：IFS 3小时、AIFS 6小时间隔的0—144小时探空预报查询。
- `/api/v1/forecast/cache/status`：预报更新监测与本地周期缓存状态。
- `/api/v1/forecast/surface/58362?date=2026-07-26&cycle=00&model=ifs`：宝山单点地面时序。
- `/api/v1/forecast/sounding/58362?date=2026-07-26&cycle=00&model=ifs&step=0`：宝山指定时效预报探空。
- `/?station=58362&date=2026-07-26&cycle=00&view=skewt`：可分享的交互式探空入口。
- 本地开发服务器默认使用 `127.0.0.1:8765`。当前 Windows 环境保留了包含 `8000` 的端口范围，不能使用 Uvicorn 默认端口。

## 已知风险

- 当前环境原先没有安装 FastAPI 和 Uvicorn，需要创建虚拟环境并安装 `requirements-web.txt`。
- 天地图服务来源已确定，但尚未配置域名受限令牌；底层服务审图号不能代替本站专题地图审图号。
- q-weather 与 Wyoming 都属于外部服务，必须增加超时、限流和回退。
- ECMWF MARS 适配器已完成，但当前账户尚未获准访问 `services/mars`；在权限开通前，Open Data 回退仍会下载所选消息的全球 0.25° 网格，不适合作为长期高并发单点服务。

- 仓库现有 `MeteoMap/main_plot.py`、`logo.png` 和 `assets/` 包含用户未提交变更，网页改造不得覆盖这些改动。
