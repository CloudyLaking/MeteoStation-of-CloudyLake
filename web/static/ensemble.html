资料与储存策略

本站通过 Open-Meteo Ensemble API 按需读取 ECMWF AIFS ENS 与 Google WeatherNext 2 的逐点集合结果。页面不插值伪造成员；服务端只保留最长 30 分钟、最多 96 个位置的内存缓存，重启即清空。

时间统一使用 UTC。来源和模型标识随每次响应返回；使用资料时应同时遵守上游模型与 Open-Meteo 的许可和署名要求。
